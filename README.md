# Predicting student grade using Bayesian Knowledge tracing and Deep learning ![Streamlit website](https://bramstudentgradeapp.streamlit.app/)

S student performance is typically measured at a single point in time, an exam, but this can lead to false positives where students got lucky or unlucky and basically failed a class when they have mastered the subject. This project tries to give a mastery score to a student to give a broader picture on the performance of a student.
